## 📖 项目介绍

BlueNote 是一款**仿小红书风格的社区笔记系统**。项目参考小红书产品形态设计，主打图文笔记分享、用户社区互动。
用户可以发布图文笔记、浏览推荐内容、点赞收藏、评论互动，打造轻量化的生活分享社区。

## ✨ 核心功能

- 📝 笔记发布：支持图文形式创作笔记，编辑标题与正文
- 🔍 内容浏览：首页信息流推荐，浏览其他人分享的笔记
- ❤️ 社区互动：笔记点赞、收藏、评论，支持用户之间交流
- 👤 用户中心：个人主页，管理自己发布的笔记、收藏内容
- 🏷️ 标签分类：笔记打上标签，方便内容归类与检索

## 🎯 项目目标

本项目以小红书作为参考原型，复刻其核心的社区笔记体验，用于学习、开发与演示社区类产品的前后端实现。

> 
> 本项目仅用于技术学习与演示，非商业项目。
